# 🎨 Colorama Quick Start Guide (Python)

**Colorama** makes it easy to print colored text in the terminal using Python. It works on Windows, Mac, and Linux.

## 🧱 Basic Setup

Before using Colorama, you need to initialize it:

```python
from colorama import init, Fore, Back, Style

init()
```

---

## 🎯 Examples

### 1. Change Text Color

```python
s = Fore.RED + "This text is red!"
t = Fore.GREEN + "This text is green!"
print(s)
print(t)
```

### 2. Change Background Color

```python
s = Back.YELLOW + "Yellow background!"
print(s)
```

### 3. Reset to Normal Style

```python
print(Style.RESET_ALL + "Back to normal.")
```

### 4. Combining Styles

```python
print(Fore.BLUE + Back.WHITE + Style.BRIGHT + "Bright blue text on white background")
```

### 5. Using it in Variables

```python
error_msg = Fore.RED + "Error: Invalid input!" + Style.RESET_ALL
print(error_msg)
```

---

## 🧼 Resetting Styles

To avoid affecting the rest of the terminal output, you either have to 

1.  Use  `Style.RESET_ALL` after styled text.
OR
2.  Initialize colorama with `init(autoreset=True)`.  This means you don't need to manually add `Style.RESET_ALL` — it's done for you after each print call.
